Overview

#

API cung cấp đầy đủ nhóm RESTful API, được chia thành AI Model APIs và Management APIs. Bộ tài liệu này giữ nguyên hướng sử dụng thực tế của tài liệu gốc: gọi mô hình AI bằng định dạng tương thích OpenAI, đồng thời quản trị người dùng, token, thanh toán, kênh và thống kê từ cùng một backend.

Known placeholder route families

  • /v1/files
  • Các resource batch/uploads/assistants-style còn chưa hoàn thiện trong một số bản triển khai.
  • Các endpoint chỉ xuất hiện trong menu tài liệu nhưng chưa có backend support đầy đủ.
Online Debugging

Bạn có thể kiểm thử endpoint trực tiếp thông qua playground hoặc gửi request đến domain của bạn. Cấu trúc hiển thị dưới đây tập trung vào endpoint, header, body, response và code examples để dùng ngay.

AI Model APIs

#

AI Model APIs tương thích OpenAI API format và là phần giao tiếp chính để truy cập các năng lực AI. Nhóm này bao gồm model listing, chat, responses, completions, embeddings, rerank, moderation, audio, realtime, images, video và một số placeholder endpoints cho các khả năng đang trong lộ trình triển khai.

Capability Primary endpoint Description
Model discovery Liệt kê model khả dụng và tự nhận diện định dạng trả về theo header.
Chat Tạo phản hồi từ lịch sử hội thoại, hỗ trợ stream và non-stream.
Responses Responses API cho multi-turn, tool calling, reasoning.
Embeddings Chuyển text thành vector embeddings.
Images Tạo ảnh bằng mô hình AI tương thích OpenAI image generation format.
Video Tạo video AI bất đồng bộ và theo dõi tiến trình tác vụ video generation.
Unimplemented Nhóm endpoint placeholder chưa được triển khai hoàn chỉnh trong hệ thống hiện tại.

Management APIs

#

Management APIs phục vụ thao tác backend như cấu hình hệ thống, user management, token management, payment, logs, statistics, tasks, groups, vendors và các luồng xác thực. Đây là phần quan trọng để xây dựng dashboard vận hành hoàn chỉnh.

  • System status, initialization, homepage content, pricing và legal pages.
  • Đăng nhập, đăng ký, OAuth và 2FA cho người dùng.
  • Quản lý token, channel, model và redemption workflow.
  • Thống kê usage, logs, tasks và business operations.

Authentication

#

Phần lớn AI Model APIs dùng Bearer Token trong header theo định dạng Authorization: Bearer sk-xxxxxx. Một số endpoint nhận diện format đầu ra theo header: x-api-key và anthropic-version cho Anthropic/Claude, hoặc x-goog-api-key hay query key cho Gemini.

Authorization Header 
Authorization: Bearer sk-xxxxxx

Chat Completions

#

ChatCompletions Format · POST

POST

Tạo phản hồi từ lịch sử chat. Hỗ trợ streaming và non-streaming responses, tương thích với OpenAI Chat Completions API. Đây là endpoint phù hợp khi bạn muốn giữ workflow dựa trên messages cổ điển.

Endpoint variants

  • OpenAI ChatCompletions: POST /v1/chat/completions
  • OpenAI Responses: POST /v1/responses
  • Native Claude format: message-style request flow cho kênh Anthropic.
  • Gemini relay format: endpoint tương thích cho các model Gemini.

Request Body

Field Type Required Description
model string Yes Model ID.
messages array<object> Yes Danh sách message trong hội thoại.
temperature number No Nhiệt độ sampling. Mặc định 1.
top_p number No Nucleus sampling. Mặc định 1.
n integer No Số lượng completion. Mặc định 1.
stream boolean No Bật SSE streaming. Mặc định false.
stream_options object No Tùy chọn stream bổ sung.
stop string | array<string> No Stop sequences.
max_tokens integer No Số token tối đa.
max_completion_tokens integer No Giới hạn completion token.
presence_penalty number No Mặc định 0.
frequency_penalty number No Mặc định 0.
logit_bias object No Tùy chỉnh token bias.
user string No Định danh người dùng cuối.
tools array<object> No Khai báo tools.
tool_choice string | object No Chiến lược chọn tool.
response_format object No Yêu cầu kiểu output.
seed integer No Seed để tái lập.
reasoning_effort string No low | medium | high cho model reasoning.
modalities array<string> No Các modality đầu ra.
audio object No Tùy chọn audio output.

Response semantics

  • 200: trả về object chat.completion cùng choices và usage.
  • 400: lỗi request body, model, tool schema hoặc tham số không hợp lệ.
  • 429: vượt giới hạn tốc độ hoặc quota hiện tại.

Responses

#

Responses Format · POST

POST

OpenAI Responses API được dùng để tạo phản hồi từ model, hỗ trợ multi-turn conversations, tool calling, reasoning và những workflow hiện đại hơn so với format chat completions truyền thống.

Endpoint coverage

  • Main endpoint: POST /v1/responses
  • Conversation continuation: dùng previous_response_id để nối multi-turn workflow.
  • Tool orchestration: hỗ trợ tools, tool_choice và reasoning.

Response object highlights

  • Trả về object response với status, output và usage.
  • output có thể chứa text segments, tool results hoặc reasoning-oriented items.
  • Phù hợp cho các workflow agent/tool calling hiện đại hơn Chat Completions.

Rerank

#

Document Reranking · POST

POST

Rerank danh sách tài liệu theo mức độ liên quan với query.

Operational details

  • POST /v1/rerank chấm điểm mức liên quan giữa query và document list.
  • Hữu ích cho retrieval-augmented generation khi cần sắp xếp lại kết quả tìm kiếm.
  • Các response thường chứa relevance_score và index của document được chấm điểm.
Field Type Required Description
model string Yes Rerank model ID.
query string Yes Văn bản truy vấn.
documents array<string | object> Yes Danh sách tài liệu cần sắp xếp lại.
top_n integer No Chỉ lấy N kết quả đầu.
return_documents boolean No Mặc định false.
cURL 
curl -X POST "https://your-domain/v1/rerank" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "rerank-english-v2.0",
    "query": "string",
    "documents": ["string"]
  }'

Moderations

#

Native OpenAI Format · POST

POST

Kiểm tra nội dung text có vi phạm usage policy hay không. Đây là công cụ compliance và không thay thế trách nhiệm safety governance, báo cáo lạm dụng hoặc cơ chế audit phía deployer.

  • Kết quả thường bao gồm flagged, categories và category_scores.
  • Nên kết hợp với logging, review flow và abuse handling của chính hệ thống triển khai.

Realtime Speech

#

Native OpenAI Format · GET

GET

Thiết lập kết nối WebSocket cho các cuộc hội thoại thời gian thực. Đây là WebSocket endpoint và yêu cầu kết nối bằng giao thức WebSocket. Ví dụ URL: wss://api.example.com/v1/realtime?model=gpt-4o-realtime.

Session lifecycle

Images

#

OpenAI Image Format · POST

POST

Nhóm Images cung cấp giao diện tạo ảnh AI tương thích OpenAI image generation API. Theo tài liệu gốc, đây là nơi dùng để sinh hình ảnh từ prompt và mở rộng sang các workflow như chỉnh sửa hoặc biến thể ảnh tùy năng lực model được bật trong hệ thống.

Endpoint variants

  • Generate Images: POST /v1/images/generations

Use cases

  • Tạo ảnh mới từ prompt văn bản.
  • Gọi các model image generation như gpt-image-1 hoặc các model tương thích khác.
  • Mở rộng sang image edits/variations nếu channel upstream hỗ trợ.

Video

#

Video Generation · POST

POST

Nhóm Video dùng cho AI video generation theo mô hình bất đồng bộ. Theo tài liệu API, đây là nơi tạo video task, sau đó truy vấn trạng thái và lấy kết quả khi quá trình render hoàn tất.

Endpoint-level flow

  • Create video: POST /v1/videos
  • Check task status: tuỳ vendor/implementation có route truy vấn trạng thái riêng.
  • Fetch result: đọc metadata task hoặc URL video đầu ra sau khi render xong.

Workflow

  • Gửi yêu cầu tạo video với prompt và cấu hình model.
  • Nhận về task hoặc job identifier.
  • Polling endpoint trạng thái để biết tiến trình xử lý.
  • Lấy URL kết quả hoặc metadata sau khi tác vụ hoàn thành.

size string No Độ phân giải đầu ra.

Unimplemented

#

Theo tài liệu chính thức, API cũng liệt kê một nhóm endpoint placeholder chưa được triển khai. Các mục này đại diện cho các capability tương lai như file management hoặc các tài nguyên phụ trợ khác, nhưng hiện tại chưa sẵn sàng cho production use trong bản triển khai mặc định.

Implementation status

Nếu bạn gặp các route kiểu /v1/files hoặc các route tương tự thuộc nhóm placeholder, hãy coi đó là endpoint dự phòng/roadmap. Chỉ nên dùng khi upstream channel và backend API instance của bạn đã xác nhận hỗ trợ rõ ràng.

Examples of placeholder capability groups

  • Files
  • Batch-style resource orchestration
  • Các capability mới xuất hiện trong OpenAI-compatible roadmap nhưng chưa được bật mặc định

System

#

Nhóm System chứa các endpoint thông tin công khai, trạng thái hệ thống và luồng khởi tạo ban đầu. Những endpoint public như about, notice, pricing hoặc policy thường được frontend dùng trước khi người dùng đăng nhập; các endpoint admin như status test dùng cho kiểm tra vận hành.

Operation Method Endpoint Auth Purpose

Get Model List GET /api/models User login Lấy danh sách model trong hệ thống quản trị.
